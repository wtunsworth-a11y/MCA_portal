# Portal logos

Sourced from the project's logo folder (Google Drive) and used by `js/credits.js`.
Attribution differs by placement (per the project's rules — see `credits.js`):

- **Every page footer:** EU (funding lockup) + CIFOR-ICRAF + Oro Provincial Government.
- **Title page (home) + Acknowledgements page (`credits.html`):** the full set —
  EU + EU-FCCB + CIFOR-ICRAF + Oro Provincial Government + PNG National Government.

Logos render on a **white band** because the EU "Funded by" lockup (dark-blue text)
and the colour crests need a light background to stay legible on the dark site.

| File | Organisation | Source file | Size |
|---|---|---|---|
| `eu-funded.png` | Funded by the European Union (horizontal lockup) | Logo_EU_v1.png | 397×88 |
| `eu-fccb.png` | EU-FCCB — Papua New Guinea (programme) | Logo_EU_FCCB.png | 171×64 |
| `cifor-icraf.png` | CIFOR-ICRAF (colour, with World Agroforestry) | CIFOR-ICRAF-logo.png | 866×364 |
| `opg.png` | Oro Provincial Government | Logo_Oro Province.png | 155×152 |
| `dnpm.png` | Government of Papua New Guinea (national crest) | Logo_Gov PNG.png | 185×123 |

Not used on the portal: MCF, the square EU variant (Logo_EU_v2), and the white CIFOR
variant (the dark site uses a white logo band, so the colour CIFOR is correct).

To change the EU programme wording/grant number, edit `FUNDING.programme` in `js/credits.js`.
